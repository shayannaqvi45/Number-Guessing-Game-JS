## 📌 Project Overview

**Number Guessing Game** is a fun and interactive browser-based game built with HTML5, CSS3, and Vanilla JavaScript. The game generates a random number between **1 and 100** and challenges the player to guess it within **10 attempts**. It provides instant feedback on every guess, logs previous attempts, validates user input, and allows the player to start a fresh session once the game ends.

---

## ✨ Features

- 🎲 **Random Number Generation** — Generates a new secret number (1–100) every session
- 🔟 **10 Attempt Limit** — Player must guess correctly within 10 tries
- 📢 **Instant Feedback** — Tells the player if their guess is Too High or Too Low
- 📋 **Attempt Logger** — Tracks and displays all previous guesses
- ✅ **Input Validation** — Handles invalid or out-of-range inputs gracefully
- 🔄 **New Game Button** — Dynamically resets the game for a fresh session

## ▶️ How to Run

1. Download or clone this repository
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, etc.)
3. No local server, installation, or build process required!

---

## 🎮 How to Play

1. The game picks a **secret number between 1 and 100**
2. Type your guess in the input field and click **Submit**
3. The game tells you if your guess is **Too High** or **Too Low**
4. Keep guessing — you have **10 attempts** to find the number!
5. Win or lose, click **New Game** to play again 🔄
